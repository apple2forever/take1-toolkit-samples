# 어셈블리에서 SN 씬 재생

**[전체 어셈블리 소스](sn_sample.s)** · **[BASIC 로더](hello.bas)** · **[호출 상수](t1scene.inc)**

샘플 디스크로 부팅하거나 BASIC에서 `RUN HELLO`를 실행합니다.
Take 1 로고 씬 `SN.TK`의 83프레임을 한 번 재생합니다.

- 재생 완료: 마지막 화면을 유지하고 키를 기다립니다. 아무 키를 누르면 BASIC으로 복귀합니다.
- 재생 중 ESC: 즉시 BASIC으로 복귀합니다.

## BASIC 로더와 어셈블리의 역할

BASIC 로더는 `HIMEM:8192`를 설정하고 `T1SC.INSTALL`을 실행합니다.
씬·액터·배경 데이터를 메모리에 준비한 뒤 `$6000`의 `SN.SAMPLE`을 호출합니다.
설치기의 임시 영역은 샘플 프로그램과 데이터가 재사용합니다.

어셈블리 클라이언트는 배경과 씬 파라미터를 설정하고 `JSR $8E00`으로 엔진을 호출합니다.
**씬 안의 포즈·좌표·템포·화면 교대·배경 복원은 원본 Take 1 엔진이 처리합니다.**
조이스틱 예제처럼 호출자가 매 프레임 포즈를 선택할 필요는 없습니다.

| 영역 | 용도 |
|---|---|
| `$0300–$03CF` | 씬 파라미터와 액터 테이블 |
| `$0800–$1FFF` | BASIC 프로그램·변수·문자열 |
| `$2000–$5FFF` | HGR 화면 1·2 |
| `$6000–$60D5` | `SN.SAMPLE` 클라이언트, 214바이트 |
| `$6200–$67F3` | `SN.TK` 씬 |
| `$6800–$6C69` | `AC.PTK4` 액터 |
| `$6E00–$8DFF` | `HGR.TK` 배경, 8192바이트 |
| `$8E00–$95FF` | 호출 게이트·사운드·작업 영역 |
| LC bank 1 `$D000–$DFFF` | 원본 씬 프로젝터, 4096바이트 |
| LC 공통 `$E000–$FFFF` | 배경 복원용 화면, 8192바이트 |

`HGR.TK`는 미리 해제한 원본 배경 화면입니다. 샘플은 압축된 BK 파일을 직접 풀지 않습니다.
DOS 버퍼가 `$9600` 이상인 표준 MAXFILES 3 이하 구성을 사용합니다.

## 소스의 실행 순서

1. `start`에서 호출 상태를 저장하고 설치 표식 `T1SC`를 확인합니다.
2. `clear_params`에서 파라미터 블록을 초기화합니다. `$03D0`부터의 DOS 벡터는 유지합니다.
3. 씬 주소, 재생 길이, 배경 주소, 전체 화면 윈도와 콜백 주소를 설정합니다.
4. 액터 테이블에 `AC.PTK4`의 스냅샷 수와 메모리 주소를 등록합니다.
5. A=`CMD_BACKGROUND`로 엔진을 호출하여 배경을 표시 화면 두 장과 복원 화면에 복사합니다.
6. A=`CMD_PLAY`로 엔진을 호출합니다. 원본 `$D024` 씬 루프가 전체 장면을 재생합니다.
7. 정상 완료면 `wait_key`에서 키를 기다립니다. ESC 중단이면 바로 종료합니다.
8. `finish`에서 텍스트 화면과 호출 상태를 복구하고 RTS로 BASIC에 돌아갑니다.

## 주요 파라미터

주소와 명령 상수는 `t1scene.inc`에 모여 있습니다.

| 상수 | 샘플 값 | 의미 |
|---|---|---|
| `SCENE_HEADER` | `$6200` | SN 파일의 헤더 주소 |
| `FRAME_LIMIT` | `$FFFF` | 장면 끝까지 재생 |
| `BACKGROUND` | `$6E00` | 8KB 배경 화면 주소 |
| `WIN_LEFT` / `WIN_RIGHT` | 0 / 40 | 수평 윈도, 7픽셀짜리 HGR 바이트 열 |
| `WIN_TOP` / `WIN_BOTTOM` | 0 / 192 | 수직 윈도, 픽셀 줄 |
| `FIRST_PAGE` | `$20` | 처음 그릴 HGR 화면 |
| `ACTOR_COUNT` | 1 | 액터 파일 개수 |
| `ACTOR_TABLE` | 스냅샷 수, 주소 lo, 주소 hi | 액터마다 3바이트 |
| `SOUND_CALLBACK` | `$9000` | 원본 사운드를 실행하는 진입점 |

우측과 아래쪽 윈도 경계는 포함하지 않습니다. 프레임 콜백은 씬 엔진이 상위 RAM을
선택한 상태에서 호출하므로, 샘플처럼 RTS로 끝내거나 ROM/DOS에 의존하지 않는 처리를 사용합니다.

다른 SN 파일을 재생하려면 그 씬이 참조하는 액터와 필요한 배경도 함께 준비하고,
주소·개수·액터 테이블을 맞춰야 합니다.

## 두 예제를 바꿔 실행할 때

씬과 조이스틱 예제는 같은 LC bank 1을 사용합니다. 각 BASIC 로더가 자기 설치기를
다시 실행하므로 `RUN HELLO`와 `RUN JOYSTICK CONTROL`을 번갈아 실행할 수 있습니다.
소스는 샘플 클라이언트와 호출 규약을 제공하며, 원본 엔진 내부 소스는 포함하지 않습니다.
